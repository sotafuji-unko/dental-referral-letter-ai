# AI紹介状作成ツール

歯科医院で作成する紹介状（診療情報提供書）を、Gemini APIを使って音声メモから自動生成するGoogle Apps Scriptツールです。同じロジックを、用途に応じて2つの形で実装しています。

## 背景・課題

歯科医院では、他院への紹介状（診療情報提供書）を定型フォーマットで作成する必要があります。患者情報・紹介目的・特記事項を都度手入力するのは手間がかかり、文面の体裁（余白・フォントサイズ・配置）を整える作業も発生します。

このツールは、音声入力（またはメモ書き）した内容を、AIが紹介状としての体裁に自動整形してくれるようにしたものです。

## 2つのバージョン

### [`document-version/`](./document-version)

Googleドキュメントに直接バインドされたスクリプト。ドキュメントを開いて音声メモを書き込み、メニューから実行するだけで、同じドキュメント内が紹介状のレイアウトに書き換わります。UIを介さず、いつも使っているドキュメント上で完結するのが特徴です。

### [`portal-version/`](./portal-version)

Webアプリ（ポータルサイト）として公開する版。専用ページのフォームに音声メモを貼り付けて生成ボタンを押すと、Google Docsとして紹介状が新規作成され、プレビュー・Docsを開く・印刷までをその場で行えます。

## できること（共通）

- 自由記述の音声メモをGemini APIに渡し、紹介状の文面（発行日・紹介先・患者情報・紹介目的・特記事項）を生成
- 生成結果をもとに、フォントサイズ・太字・配置・余白（A4 1枚に収まるレイアウト）を自動調整してGoogle Docsに書き込み
- 患者氏名は全角カタカナに自動変換
- クリニックのロゴ・説明用画像を紹介状の右下に自動配置（説明用画像の有無を選択可能）
- 特定の紹介先医療機関の場合、担当医名の表記ゆれを防ぐため固定文言に自動置換（サンプル実装）

## 技術スタック

- Google Apps Script（`document-version` は Document 拡張機能、`portal-version` は Web アプリとして実装）
- [Gemini API](https://ai.google.dev/)（`gemini-2.5-flash`）による文章生成
- Google Docs API（`DocumentApp`）によるレイアウト自動生成

APIキーはコードに直書きせず、スクリプトプロパティ（`PropertiesService`）から読み込む構成にしています。

## 使い方

**document-version**
1. Googleドキュメントを開き、音声入力またはメモ書きで紹介したい内容を自由に記述する
2. メニューの「AI紹介状」→「紹介状を作成」を実行
3. 説明用画像を入れるかどうかのポップアップに回答する
4. ドキュメントの内容が紹介状の体裁に自動で整形される

**portal-version**
1. Webアプリのページを開く
2. テキストエリアに音声メモを貼り付け、必要に応じて説明用画像のトグルを設定
3. 「紹介状を生成する」を押すと、Google Docsとして紹介状が新規作成される
4. プレビューを確認し、Docsを開く／印刷から仕上げる

## 補足

- 本リポジトリのコードは、実際にクリニックで運用しているツールから、患者情報や実在する連携医療機関名・医師名などの個人情報・機微情報を除去し、サンプル値に置き換えたものです。
- 画像ファイルID（`IMAGE_ID_DEFAULT` / `IMAGE_ID_STAFF_YES`）や、紹介先医療機関の固定文言（`applyDoctorOverride`）はプレースホルダーです。実際に使う場合は、ご自身のGoogle DriveファイルIDや文言に置き換えてください。
